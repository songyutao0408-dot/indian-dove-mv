# 项目：《印第安老斑鸠》MV（纯代码动画，自娱自乐作品）

你要独立完成一支约 5 分 04 秒的 MV，全部画面由代码绘制（SVG + React 动画），不使用任何外部 AI 绘图或视频生成工具。最终输出一个带原曲音轨的 mp4 文件。

## 一、技术方案
- 框架：Remotion（React + TypeScript）。所有角色、场景都用 SVG 组件手写，用 interpolate / spring 驱动动画，用 <Audio> 挂载原曲，最后用 Remotion CLI 渲染。Remotion 需要的静态文件请从 assets/ 复制到 public/。
- 规格：1920×1080，24fps，总时长以音频实际长度为准（约 304 秒）。
- 动画节奏：角色动作用"一拍二"的方式，即每 2 帧更新一次姿态（相当于 12 张/秒），模仿老式手绘动画的顿挫感。镜头运动和背景视差保持 24fps 平滑。
- 字体：从 Google Fonts 下载 ZCOOL KuaiLe（站酷快乐体）作为歌词字体，标题用 Rye 或同类西部风格英文字体。字体文件放在 public/fonts/ 本地加载。
- 音频分析：用 Python + librosa 分析原曲，导出 beats.json（节拍时间点）和 energy.json（每 0.5 秒的能量值）。剪辑点、角色蹦跳、画面抖动尽量卡在节拍上。

## 二、输入文件（都在 assets/ 里）
- 原曲：assets/ 里的 .mp3 文件（文件名不限）。
- 歌词时间轴：assets/ 里的 .lrc 文件（文件名不限）。读取时先尝试 UTF-8，乱码就改用 GBK。
- 段落时间表：assets/timeline.json。里面是全片的段落划分（S0–S19）、每段的起止秒数、白天/夜晚/做旧模式、片头卡时间和两个笑点的时间窗口。分镜以它为准。
- LRC 的处理规则：
  - 前三行（歌名、作词、作曲）不做底部字幕，改为片头卡，时间见 timeline.json 的 title_cards。
  - 空白时间戳（只有时间、没有文字的行）表示这里字幕清空。
  - 歌词有大段重复，把每一句分配到段落时，按时间戳落在哪个段落的区间来判断，不要按文字匹配。
- S18 的结束时间是估计值。用 energy.json 和听感判断人声实际结束的位置，校准 S18 / S19 的分界。

## 三、视觉风格圣经（所有镜头必须遵守）
风格定位：1940–50 年代美式手绘卡通短片 × 老西部片。荒诞、夸张、热闹，一本正经地胡闹。

色板（白天）：
- 天空：#F7D58B → #F0A15E → #E07A4F（分成三四条硬边色带，不做平滑渐变）
- 平顶山／峡谷：#C1502E，暗面 #8E3B2A，最远层 #D98A6A
- 沙地：#E9C48F，阴影 #C99A62
- 仙人掌：#5E8C4A，暗面 #3F6634
- 描边：#3A2418（深棕黑，不用纯黑），线宽 3–5px，略带粗细变化
- 高光／奶油色：#F6E7C8

色板（黄昏）：天空 #F0A15E → #C8607A → #6B4A7A，物体偏暖红。
色板（夜晚）：天空 #2E3A5C → #5B4A7A，月亮 #F6E7C8，物体整体压暗并偏紫。
色板（黎明）：天空 #5B4A7A → #E8A0A0 → #F7D58B。
做旧模式（sepia，用于小镇和说唱段）：整体加棕褐滤镜、竖向划痕、闪烁的黑点，模仿老胶片。

色调切换要做成可插值的全局主题，在 timeline.json 中模式带"→"的段落里平滑过渡。

质感后期（做成全局 overlay 组件，全片叠加）：
- 胶片颗粒：用 SVG feTurbulence 生成，每 2 帧换一次 seed
- 画面轻微抖动（gate weave）：±1.5px 的随机位移
- 暗角（vignette）
- 整体轻微褪色，饱和度约为 90%

背景构图：采用 3–4 层视差（远山、中景峡谷、近景仙人掌和石头、前景草丛），镜头横移时各层速度不同。远景用平涂的大色块，不画细节。

经典卡通语言（多用）：
- 挤压拉伸、动作前的预备姿势、速度线、残影
- 撞击时冒星星，跑动时起尘土云，惊吓时眼睛弹出
- 转场用"光圈收缩"（黑色圆形向中心收拢再打开）和木牌翻转
- 角色"秀逗"时，眼睛变成转动的螺旋

## 四、角色设定（先做角色，再做场景）
每个角色写成独立的 SVG React 组件，用 props 控制表情和姿态（pose、expression、blink 等），保证全片造型统一。

主角：印第安老斑鸠
- 体型：圆滚滚的身体，腿特别短（大约身高的 1/6），走路一颠一颠的
- 羽毛稀疏：灰褐色身体（#9C8A78），胸口偏粉灰（#C9A9A0）。身上有几处秃斑，头顶只剩三根翘起的毛
- 头部：大而下垂的眼皮，平时半睁着，一副没睡醒的样子。喙短，略带弯钩
- 印第安元素：头上绑一根红黄相间的长羽毛，脖子挂一串木珠项链
- 表情集：发呆、饿昏（眼冒金星，肚子咕咕叫，有声波线）、秀逗（螺旋眼加傻笑）、伤心（大泪滴喷出来）、生气（头顶冒烟、羽毛竖起）、心动（眼睛变成心形，脸红）、学人说话（嘴巴开合，冒出对话气泡）、困惑（头上冒问号）、睡觉（Zzz）
- 动作集：短腿踱步、原地打瞌睡、扑腾翅膀但飞不起来、躺倒、跳舞

母斑鸠：身形纤细，羽毛蓬松柔顺，带长睫毛，头上插一朵沙漠小花，走路扭来扭去
乌鸦：黑色，戴蒙面眼罩，像小偷，叼着树枝逃跑
响尾蛇：热到瘫软，舌头耷拉，满身汗珠，身体上方有热浪扭曲效果，尾巴有气无力地摇响
灰狼：瘦长，龇牙，啃骨头时骨头被咬出缺口；在说唱段换成正经脸，戴牛仔帽
秃鹰：秃头加大鹰钩鼻，在空中绕圈，眼睛一直死盯着下方
两头野牛：毛发蓬乱，鼻孔喷气，蹄子刨地，远景对冲，撞出一团尘土
蜥蜴：侧着身子横着走，像螃蟹一样，表情很淡定
害羞的仙人掌：有脸、会脸红，被看时用两只"胳膊"捂住脸，扭身躲开
像猫的狗：狗的身体，猫的动作（舔爪子、弓背、伸懒腰、追激光点），旁边可以加一个问号
海鸥：在沙漠里显得格格不入，飞过时嘴里叼着薯条
泥鳅：从干沙里钻出来，左右张望，再缩回去
牛仔：大帽檐、八字胡、皮套裤，腰间别着左轮
印第安战士（决斗对手）：按经典西部片造型，头戴羽毛冠，脸上画油彩，穿流苏皮衣，手持弓箭或左轮
巫师：披兽皮斗篷，戴羽毛面具，手摇骨头法器，念咒时身边冒出彩色烟雾和符号
酋长：戴大羽毛头冠，抱着胳膊，表情严肃，被诅咒后头顶冒出乌云
骷髅头：会动，下巴一张一合，像在抗议

## 五、分镜（段落和时间以 assets/timeline.json 为准）
总原则：平均每 3–6 秒一个镜头，剪辑点卡节拍。重复段落不能直接复用镜头，必须换机位、换时段或换动作。每个段落内，按 LRC 每句的起始时间切镜头或触发动作。

S0 前奏（约 36 秒）：开场是一张歌名卡：木牌上用西部字体写歌名，背景是放射状的太阳光芒，风滚草从卡片前滚过。8.95 秒翻到作词卡，17.91 秒翻到作曲卡，三张卡用木牌翻转衔接。26 秒左右光圈打开，进入峡谷全景的大横移，风吹过，一团风滚草滚向镜头，为第一句做准备。
S1：沙漠里钻出泥鳅 → 一只海鸥（叼薯条）飞过，泥鳅抬头看 → 大峡谷的风吹过，风滚草翻滚，镜头剧烈晃动 → 画面外传来质疑的声音（用对话气泡表现）。
S2：干涸河床上瘫着的响尾蛇，热浪扭曲，太阳有一张得意的脸 → 响尾蛇幻想雨季来临（用思维气泡画出沼泽）。
S3：灰狼啃骨头 → 秃鹰在天上盘旋，用它的主观视角俯拍 → 远方两头野牛对冲，撞出尘土云。
S4：镜头推近一座废弃的白蚁丘，老斑鸠第一次登场，饿到摇摇晃晃、眼冒金星。人声结束后的约 9 秒纯音乐里，给主角一个"亮相"定格，用木牌名牌介绍它，再让它打个大哈欠。
S5 副歌 A：老斑鸠的角色介绍段。短腿和稀疏羽毛的特写 → 晒着大太阳、旁边空水壶也一样淡定 → 秀逗时的螺旋眼 → 看到一只死掉的猎物后嚎啕大哭，泪如喷泉，旁边的秃鹰一脸莫名其妙。
S6 Hook：老斑鸠学人说话，冒对话气泡 → 害羞的仙人掌捂脸 → 蜥蜴横着走过画面 → 一系列快速闪切的怪事 → 像猫的狗伸懒腰，最后定格加问号。
S7 副歌 B：老斑鸠平时很安静（坐着发呆）→ 乌鸦偷它的窝，它瞬间暴怒追赶 → 在灌木丛旁遇见母斑鸠，时间变慢，背景变成粉色，花瓣飘落，心形眼。
S8 间奏一（约 25 秒纯音乐）：两只斑鸠的约会小片段（分享一颗仙人掌果、一起看风滚草）→ 一团风滚草被风吹远，镜头跟着它一路滚进西部小镇 → 钟楼指针走到正午 → 主街空镜，色调逐渐转成做旧胶片。这段要让观众感觉"要出大事了"。
S9 说唱（约 10 秒，7 句）：全片节奏最快的一段，每句一个镜头，1–2 秒快切。依次是：牛仔和印第安战士背对背走开 → 灰狼戴牛仔帽凑到镜头前发问 → 巫师围着篝火念咒 → 彩色烟雾冲向酋长，酋长头顶出现乌云 → 骷髅头一张一合地"抗议" → 老斑鸠像说书人一样坐在木箱上 → 最后一句时，画面像旧胶片一样烧穿变白。
S10 主歌二（黄昏到夜晚）：内容和 S1–S3 对应，但全部换机位。例如泥鳅在月光下钻出来，海鸥变成剪影，响尾蛇在夜里终于凉快了一点，野牛决斗变成远处的剪影。胶片烧穿的白光从段落开头褪去，过渡到黄昏色调，再到夜晚。
S11 导歌二：白蚁丘在月光下，老斑鸠蹲在上面看月亮。人声结束后约 4 秒，给一个安静的远景。
S12 副歌 A 二：内容同 S5，换成夜晚版本和不同的动作、角度。
S13 Hook 二：开头是念白梗（时间窗见 timeline.json 的 gags.rest）：老斑鸠真的躺进一张吊床，盖上小毯子，头顶冒出 Zzz，其他角色也一起定格。窗口结束时闹钟响，它弹起来，继续 Hook 的内容（仙人掌、蜥蜴、怪事、像猫的狗，换新的演法）。
S14 副歌 B 二：内容同 S7，夜晚版本。例如乌鸦在月光下偷窝，两只斑鸠在萤火虫中重逢。
S15 间奏二（约 20 秒纯音乐）：所有动物围着篝火开派对，跟着节拍摇摆 → 篝火渐熄，天边泛白 → 日出，白天回归。
S16 副歌 A 三：内容同 S5，白天版本。缺词梗（时间窗见 gags.missing_word）：这句只唱了半句，老斑鸠卡住，脑袋上方冒出一个问号，它敲了敲自己的头，然后接着往下。
S17 Hook 三：内容同 S6，但前面出场过的所有角色开始往峡谷前聚集。
S18 副歌 B 三：全员到齐，母斑鸠和老斑鸠站在中间。
S19 尾奏（约 33 秒）：全员排成一排，跟着节拍大合跳 → 镜头慢慢拉远到整片沙漠 → 太阳下山 → 光圈收缩，只留下老斑鸠的脸，它眨一下眼 → 黑底木牌结束卡，写词、曲、编曲的署名和一个"完"字。

## 六、歌词字幕
- 从 LRC 读取，每句在开始时间出现；遇到下一句或空白时间戳时，提前 0.2 秒淡出。
- 前三行不做底部字幕，用片头卡代替（见第二部分）。
- 样式：画面底部居中，ZCOOL KuaiLe 字体，奶油色字（#F6E7C8），3px 深棕描边，下方带一块半透明的木纹条。
- 出现动画：每个字依次从下往上弹出（逐字延迟 2 帧），用 spring 做回弹。说唱段语速很快，这一段改成整句一起弹出。
- 说唱段（S9）的字幕改成老电影插卡的样式（黑底白字，带装饰边框）。

## 八、工作流程与检查点（每个检查点都要停下来给我看）
1. 搭好工程，跑音频分析，解析 LRC 和 timeline.json，输出一份段落时间表（每段的起止时间、包含哪几句、计划几个镜头），给我确认。
2. 做出全部角色，渲染一张"角色设定图"PNG（所有角色排在一起，老斑鸠再单独展示全部表情），给我确认造型。这一步最重要，造型定了后面不再大改。
3. 做出各时段背景、小镇场景和全局质感 overlay，渲染几张场景静帧给我看。
4. 按段落逐个制作。每完成 2–3 段，就渲染一版 540p 的预览片段给我看。
5. 全部完成后，先渲染一版 540p 的完整预览，确认音画同步后，再渲染 1080p 正式版。

每完成一个检查点，都更新 PROGRESS.md：已完成什么、当前卡在哪、下一步做什么。新会话开始时先读 PROGRESS.md，再继续。

## 九、验收标准
- 老斑鸠在全片造型一致，出场的镜头至少占全片的 40%
- 歌词与演唱对齐，误差不超过 0.15 秒
- 没有静止超过 2 秒的画面（哪怕是空镜，也要有风滚草、眨眼、热浪这类微动）
- 重复段落没有任何一个和前面完全相同的镜头
- 两个间奏和尾奏都有完整的画面内容，不能只放空镜
- 最终文件：out/indian-dove-mv-1080p.mp4，带原曲音轨
